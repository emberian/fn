# listener-v6 (2026-09-26): IPv6 and several listener addresses (NNT-041, PRF-197)

Gap inventory item R7 (planning/nntp-gap-inventory-2026-09-26.md): the
listener admitted only a numeric IPv4 address, `localhost` and `::1`, and
one address.

## What changed

- `[listener] host` is one address or a comma-separated list. Each address is
  an IPv4 dotted quad, an IPv6 literal (RFC 4291 section 2.2 forms 1-3,
  optionally bracketed per RFC 3986 section 3.2.2; no port inside) or the
  name `localhost`. Grammar and projection: books/native-config.lisp
  `fn-native-config-ipv6-literal`, `fn-ncfg-listener-element`,
  `fn-native-config-listener-plan`, `fn-native-config-listener-addresses`.
  Refusals name the reason through `fn-native-config-load`:
  `:listener-address`, `:listener-unspecified` (0.0.0.0, ::),
  `:listener-mapped` (::ffff:0:0/96), `:listener-duplicate`.
- The owner (host/native/owner.lisp `fnn-owner-run-normalized`) calls
  host/native-config-host.lisp `fn-native-config-host-listener-addresses`
  and binds every projection with `fnn-listen` (AF_INET6 through
  `sb-bsd-sockets:inet6-socket`, already in io.lisp `fnn-socket-class`):
  the first on `port`, each further one on the port the first bound, each
  with its own accept worker (`fnn-owner-start-tls-accept` generalized with
  an IMPLICIT-TLS flag), and one implicit-TLS listener per address on
  `tls_port`. The TLS listener's behaviour is unchanged. `once` mode binds
  only the first.
- Exposure: host/owner-host.lisp `fn-owner-exposure-install-set` replaces
  `fn-owner-exposure-install`; the node is public when
  `fn-exp-address-publicp` holds for any projection.
- No store format, no configuration delta code, no wire code taken.

## Theorems (books/native-config.lisp)

- KEYSTONE `fn-native-config-listener-addresses-are-bindable-projections`:
  `(fn-native-config-listener-addresses H)` not `:bad` implies a cons,
  `fn-native-config-listener-projection-listp` (each `(:inet Q)`, Q four
  octets other than 0.0.0.0, or `(:inet6 A)`, A sixteen octets other than ::
  and outside ::ffff:0:0/96) and `no-duplicatesp-equal`. Host line:
  owner.lisp `fnn-owner-run-normalized` -> `fn-native-config-host-listener-addresses`.
- Supporting: `fn-ncfg-listener-plan-ok-shape`,
  `fn-ncfg-listener-element-ok-is-a-projection`,
  `fn-native-config-ipv6-literal-shape`, `fn-native-config-ipv4-address-shape`,
  `fn-ncfg-listener-element-classifies-by-definition` (which of the three
  forms each element is).
- Assurance chain: native entry `fn run` -> operator load
  (`fn-native-config-load`, refusal reason) -> `fnn-owner-run-normalized` ->
  executed subject `fn-native-config-listener-addresses` -> keystone ->
  bind(2) of each projection (A-HOST: the kernel binds what it is given).
  No maintained relation: the projection is computed once at start; a live
  reconfiguration does not rebind listeners (PKT-464 (a), not fixed here).
