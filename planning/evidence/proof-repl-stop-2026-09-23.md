# Proof REPL session stop and ownership

On the frozen BP union, `stop bpnfg` printed success while a prior same-name server, slot wrapper, and ACL2 child remained alive. The first `start` had been retried while certificate acquisition was still running: the old duplicate check looked only for a socket, which did not exist yet. A second server could replace the socket, leaving the first server unreachable by `stop`.

`start` now claims an exclusive name lock before cache acquisition and passes that open lock to its server. A retry refuses while the first start is loading or serving; a live socket from an older server is also preserved. `stop` acknowledges only after the server has signalled its own wrapper/ACL2 process group, drained its output, and released the name lock. The group leader remains unreaped until signalling, so its PID cannot be recycled for another group. A graceful termination gets one second before the owned group is forcefully terminated. No process-name search or global kill is used.

At source base `d4c40484`, `python3 -m unittest tests.test_proof_repl.ReaderTests tests.test_proof_repl.CacheStartupTests tests.test_proof_repl.ProcessLifetimeTests tests.test_proof_repl.SessionTests -v` passed ten tests on local Python 3.14.7; the new race test uses a harmless fake executable with a spawned heartbeat child, not an ACL2 farm run. `make check` passed. This tests local process and Unix-socket behavior; it is not an ACL2 proof or native BP image result.
