## Remaining boundaries

No cross-host peering, full power-loss profile, physical recovery-transition
simulation, native signature-to-Store verdict join, or complete BP application
article/receipt exchange is established here. The known missing workflow
receipt constructors were not rerun as if rebuilding supplied their semantics.
The schema change is one-way after a schema-1 article is written: an old
binary is not a qualified rollback for that Store. The subsequent old-checkpoint probe found a real migration defect:
pre-T2 `checkpoint publish STORE select` followed by the new image recovery
returns exit 4 (`checkpoint=corrupt`, selected generation does not decode).
Journal-only migration is qualified here; selected-checkpoint migration and
any reclaimed-prefix case remain open for the next repair. The running node
remains on its prior image.
