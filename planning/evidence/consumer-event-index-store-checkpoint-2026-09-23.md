# Rebuildable consumer event index checkpoint

The Store representation appends derived slot 13 after the topic projection in slot 12. Four uint32 octets select a fixed-depth radix path. The index retains the exact committed event object at each dense journal sequence; it is not an acceptance authority or a second durable journal. The record-directory success transition extends it, a model crash discards it, and successful recovery rebuilds it from exact recovered events. The configuration updater preserves the slot without copying a version-specific constructor.
