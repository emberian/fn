# Handoff, end of the October 2026 wave

Each file is one workstream's continuation, written when the wave wound down (2026-10-03): its branch and sha,
what is done and verified, what is unverified, in-flight run ids (results may be on hbox), the repair-ledger items it
owns, and the exact next steps. Start from `planning/plan-2026-10-03.md`, then the ledger
(`python3 planning/repair/repair.py list --open`), then the file for the area you take.
Review files (`*-review-1.md`) are adversarial reviews of a design or a READY.
