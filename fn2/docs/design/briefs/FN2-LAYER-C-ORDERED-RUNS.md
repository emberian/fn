2. **The write path**: a bounded active overlay per schema (InfiniFilter-shaped membership for the identity overlay, FILTERS-2026 item 3) fed by the commit batch's installed successor; sealing an overlay into a run; reserved, incremental, resumable compaction with backpressure before maintenance debt exhausts its reserve (STORAGE-DESIGN-ASTRA §4's price, stated).

4. **Checkpoint of the engine's roots** through layer B's checkpoint machine; the typed signed checkpoint claim's engine commitments (STORAGE-DESIGN §4 decision 4) produced here.
