## The five decisions
1. Unit of state: one semantic event history (prefix summary plus suffix); mutable keyed objects as folds in the same commit stream; repeated operations return their recorded outcome; discarding history needs an identified sufficient-summary rule.
2. Pinned versions: stable selection and identity; payload availability guaranteed after the reply's object lease; historical metadata for supported pins retained; long cursors re-seek.
3. Retention: classes as placement hints; one release predicate (requirements discharged, obligations released, no lease, recovery no longer needs it).
4. Integrity: a Merkle event log from the first format plus physical predecessor links and parent-held page hashes; a typed signed checkpoint claim.
5. Sealed streams: client-encrypted opaque content with an explicit public envelope.
