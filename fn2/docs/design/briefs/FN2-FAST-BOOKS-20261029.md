## The rules of the game
- **Nothing weakened.** No statement changes, no `skip-proofs`, no raised step limits, no deleted theorems, no `:guard t` where there was a real guard. A4's six drivers (`fn2/tests/*.lsp`, run as the A continuation says) exit 0 with their summary lines unchanged, and `fn2/tools/certify.sh --export-owed` leaves OWED.md byte-identical. That is the acceptance of every commit.
- **Allowed moves:** disable rule families a proof does not need (`in-theory` locally, `local` lemmas); replace a guard proof's repeated snapshots with one read; prove a shape once generically and instantiate (SOFT / functional instantiation; `fn2/books/columns.lisp` already does this for the per-array rules, read how W1 did it in `build/coordinator/fn2/lanes/a-quests/W1.REPORT.md`); split a book along a real boundary; add `:rule-classes` that stop a rewrite loop; use `defthmd` for lemmas that only one proof needs; mark `:hints` that cut search; cache a `make-event` result; turn tau off locally where it thrashes. Measure with ACL2's `accumulated-persistence` and per-event `:time`; a change without a before/after number is not a change.
- **Work in your own worktree** `/Users/ember/dev/fn/build/lanes/fn2/fast-<slice>` on branch `fn2/fast-<slice>` from current `dev`, rebasing onto dev whenever it moves (the A/D DSL seat and the D seat commit to dev continuously, mostly under fn2/books; if a book you are tuning changed on dev, rebase and re-measure before touching it again). One commit per book or per shared cause, message carrying the before/after seconds and the cause in one line, prose via `git commit -F`. Push your branch after every commit; report to main `READY <sha> <book> <before> -> <after> s <cause>` per commit, so main merges into dev while drivers are unchanged. Do not edit a book another seat has uncommitted work in (ask main if unsure: the DSL seat is on machines.lisp, squares.lisp, q1*.lisp, declare.lisp, owed.lisp; the D seat on resources*.lisp, grammar*.lisp).
