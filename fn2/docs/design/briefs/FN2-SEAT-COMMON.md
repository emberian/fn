## Three standing rules from REVIEW-SINS-20261028.md (binding on every layer)
- **Assert, never absorb.** A result is checked or the function stops; no discarded return codes, no setter that silently does nothing, no reader that returns 0 for invalid input, no clamped counter, no refusal branch on a release path. Invariants are asserted where they hold, not validated at every input. A correctness bug must fail loudly, never become a liveness bug.
- **The DSLs generate meaning, not storage.** Enums are compared by their declared names, never as 0..3; fields are addressed by name, never by position; a function takes a packed handle, never 17 positional words; a layout is compiled by the DSL into a codec, never interpreted at run time; one named sentinel, never a scattered 4294967295. If the derived path stops at the defstobj, the DSL is a template engine and the twin comes back by hand.
- **Layers meet at seams.** A layer reaches another's state only through a registered seam (R5c's core children, defmachine's registry, the pool's exports); the scheduler holds no machine's id; a directory carries no kind-specific flag; layer A's books are a library and the core INSTANCE is assembled in one top-level book, so adding a machine kind recertifies the assembly, not the library.

## Composition discipline (ember, 2026-10-28: "not just suffering a proliferation of conceptual linkages")
The 5.1.1 fragment is the base theory; every wider construction is an extension that must be conservative over it or declare exactly what it changes as a decision. A linkage counts only when its morphism is written down and something is checked across it; otherwise it is a footnote. Two additions that are one construction are merged. Each modality or primitive earns its place with a checker, a refusal word, or a record kind.

## The one-minute rule (ember, 2026-10-28: "no book should be over 1m")
No fn2 book certifies in more than 60 s on the laptop. A book over 60 s is a red the owning layer fixes before its next quest commits: profile per event (ACL2's accumulated-persistence or :time per event), name the family, fix it by proving the shape once generically, by splitting the book along a real boundary, by disabling what the proof does not need, or by a cheaper statement of the same contract; never by raising a step limit or weakening a statement. Each layer's continuation carries a table of its books' certify times, refreshed after every quest; the layer doc records any book that cannot meet the rule with the reason and the number. The inner loop target is seconds per book, the closure only at a milestone.
