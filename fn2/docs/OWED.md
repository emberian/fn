# Recorded obligations

`defthm-owed` translates each statement and records it in the `fn2-owed` world table. It creates no theorem. These obligations remain unproved; unit-test witnesses are executable evidence, not proofs.

`pool.lisp` defines the predicates used by both the statements and the evaluated teeth. Its logical dispatcher invokes the actual pool exports. The read-only invariant and evidence predicates allocate only in tests/checkers; they are never runtime guards or served operations. The `defun-nx` statements and dispatcher cannot execute. Tests evaluate their shared hypothesis and conclusion predicates around calls of the real exports, checking both the complete antecedent and conclusion; each negative tooth falsifies both.

The semantic invariant is stronger than the constant-work runtime shape guard. No production path scans the slot table or validates a whole pool. `:retired` is the successful terminal release transition; refusal immutability applies to `:stale`, `:bounds`, `:state`, `:owner`, and `:exhausted`.
