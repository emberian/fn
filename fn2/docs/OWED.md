# Recorded obligations

`defthm-owed` translates each statement and records it in the `fn2-owed` world table. It creates no theorem. These obligations remain unproved; unit-test witnesses are executable evidence, not proofs.

`pool.lisp` defines the predicates used by both the statements and the evaluated teeth. Its logical dispatcher invokes the actual pool exports. The read-only invariant and evidence predicates allocate only in tests/checkers; they are never runtime guards or served operations. The `defun-nx` statements and dispatcher cannot execute. Tests evaluate their shared hypothesis and conclusion predicates around calls of the real exports, checking both the complete antecedent and conclusion; each negative tooth falsifies both.

The semantic invariant is stronger than the constant-work runtime shape guard. No production path scans the slot table or validates a whole pool. `:retired` is the successful terminal release transition; refusal immutability applies to `:stale`, `:bounds`, `:state`, `:owner`, and `:exhausted`.

For `vocab.lisp`, `fn2-ops-semanticp` and the snapshot/predicate helpers are executable only for tests and checkers. The logical dispatcher calls the actual exports. The row accounting equation includes retired rows: free + reserved + queued + submitted + release-pending + done + retired = O; excluding retired would be false after generation exhaustion. Outbox credits in use are reserved + queued, while `fn2-ops-outbox-credits` reports the remaining available credits.

A3 refusal rollback uses `fn2-op-unreserve` only on unpublished reservations: it restores the same generation and canonical free row. `fn2-op-finish` still increments or retires submitted lifetimes. The byte-fill obligation explicitly assumes the adapter-write initialization trace; it does not infer initialization from whatever bytes already occupy storage. These ten A3 keystones are recorded and have evaluated teeth, but are not proved. The simulator has no refinement claim.

A4 ABI integration: ROUND2 §D.2's `ArmWake` observation-generation/deadline, `Trace` payload and `ServicePosture` reason/scope have no named payload fields or setters in the A2 outstanding table. A3 acknowledges and finishes these no-result action rows, but does not invent a storage-offset encoding or implement deadline wake scheduling. A4's executor/timer work must add the payload representation and connect the simulated/native wait behavior; periodic simulator clock mailbox observations are not a proof of the earliest-deadline contract.
