# fuckin' news / formal news /᠁

fn is a news server for people and programs. It speaks NNTP. ACL2
makes every decision, and the theorems cover the functions the server
calls. Every answer is accepted, refused or uncertain.

- The guides, as a newsgroup: <https://emberian.github.io/fn/>, or
  `tin -T -r -A -p 563 -g fn.fg-goose.online`.
- As plain text: [docs/articles/](docs/articles/), from
  [the welcome](docs/articles/fn-welcome.txt).
- Engineers: [docs/README.md](docs/README.md), [AGENTS.md](AGENTS.md).

A first check needs Python 3.11: `make check`.
