Summary: How to help, the rules that do not bend, and how fn is built.

Use it, build on it, or work inside it.

*Why it matters:* Clients, gateways, packages and guides need no
ACL2.

*First check:* Python 3.11. It checks links, registries and the
docs' commands.

    git clone https://github.com/emberian/fn
    cd fn
    make check

*Inside:* SBCL and ACL2 8.7 (FN_ACL2). Certify what you changed:

    python3 tools/certify_books.py --affected-by books/THE-BOOK.lisp

*The rules:*
- ACL2 makes every decision. Host code does I/O.
- A theorem is about the function the server calls.
- No skip-proofs, defaxiom or trust tags.
- Accepted, refused and uncertain stay distinct.
- Bound work, never stored data.

*How it is built:* AI agents in parallel lanes, directed by ember.
Lessons: swarmguide/.

*Go deeper:* AGENTS.md. Pull requests against dev. AGPL-3.0.
