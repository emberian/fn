Summary: How to help, the rules that do not bend, and how fn is built.

Use fn, build on it, or work inside it. Clients, gateways and guides
need no ACL2. Newcomers are welcome to bring an AI assistant: every
guide names its files, so you can hand it the paths.

*Start:* CONTRIBUTING.md, then docs/engineering.md. Python 3.11 or
newer.

    git clone https://github.com/emberian/fn
    cd fn
    make check

*The rules that do not bend:* ACL2 makes every decision; a theorem
is about the function the server calls; accepted, refused and
uncertain stay distinct.

*How it is built:* AI agents in parallel, directed by ember
(AGENTS.md, swarmguide/). AGPL-3.0.
