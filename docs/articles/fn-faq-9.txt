Summary: What is proved, about what, and what a proof cannot promise.

fn's rules are ACL2 functions, and the theorems are about those
same functions, the ones the server runs. The usual way proves a
sketch and hopes the code agrees.

*The catch:* No proof covers your disk, a hash, or a peer's honesty.
Those are written down as assumptions (books/assumptions.lisp), and
power-cut tests on real machines check them.

*Four claims, kept apart:* written (the server calls it), proved,
tested on a built server, running on a live node.

*Go deeper:* docs/proofs.md.
