*Health codes:* health exits with the code of the first problem it
found. 0 means none; 18 means the node is not running (nothing answers
on its control socket and nothing holds the store; the next line says
how its last run ended, `last-stop exit=NN reason=...`); 19 means fn
could not check (the peer lines need a running node).

- 20 fenced: Something holds the store: a start, another command, or a
  node that does not answer. Wait and ask again. Never delete the lock.
- 21 exhausted: A counter (transactions or held space) ran out. Only an
  export and import raises it.
- 22 unqualified-profile: The store uses test settings. Make the node
  again with a mission.
- 23 space-pressure: The store is nearly full. Release what is held, or
  move to larger limits.
- 24 no-route: Articles wait to be forwarded and no BP route is set.
- 25 stranded-transfer: A peer kept refusing an article, and fn stopped
  offering it. Fix the peer.
- 26 unavailable-peer: A peer with articles waiting is not connected, or
  says try later (deferred=N: its store may be full), or its queue is
  full (saturated=N: every post is refused feed-queue-full until it
  catches up). Check peer list; ask its operator.
- 27 receipt-debt: Forwarded articles wait for their receipts.
- 28 disk: The disk is stalled (a write has waited past its stall
  deadline; posters were told uncertain) or full (free space below what
  a write needs). Look at the device; free space. The node recovers by
  itself. (Provisional: this state and its code wait on a decision.)

*Refusals:* A refused post is answered "441 posting failed;" and one of
these. The log line starts refused and names the reason.

- unparsable: the article is not valid syntax
- header-fields-limit: the header has more fields than the profile's
  max-header-fields
- header-lines-limit: the header has more lines than the profile's
  max-header-lines
- header-octets-limit: the header has more octets than the profile's
  max-header-octets
- group-read-only: a group this article names is read-only here (LIST
  ACTIVE status n)
- approval-not-moderator: Approved is accepted only from a moderator of
  each moderated group named (LIST ACTIVE status m)
- moderation-unavailable: a moderated group is named and the article
  could not be forwarded to its moderation queue
- injection-info: Injection-Info must not be supplied
- xref: Xref must not be supplied
- injection-date-present: Injection-Date must not be supplied
- path-present: Path must not be supplied
- path-malformed: Path is not a valid path
- path-duplicate: Path appears more than once
- path-posted: Path must not carry a POSTED diagnostic
- newsgroups-missing: Newsgroups is required
- newsgroups-duplicate: Newsgroups appears more than once
- newsgroups-invalid: Newsgroups is not a valid newsgroup list
- message-id-duplicate: Message-ID appears more than once
- message-id-invalid: Message-ID is not a valid identifier
- from-missing: From is required
- from-duplicate: From appears more than once
- from-invalid: From is not a valid mailbox list
- subject-missing: Subject is required
- subject-duplicate: Subject appears more than once
- date-duplicate: Date appears more than once
- no-groups: no newsgroup was named
- unknown-group: a named newsgroup is not carried here
- oversize: the article exceeds the configured size
- clock-unusable: this server has no usable clock reading
- clock-out-of-range: this server clock is outside the modelled range
- posting-disallowed: posting is not permitted
