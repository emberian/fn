Summary: The OpenBSD 7.9 differences.

OpenBSD 7.9 runs fn. Four things differ.

*The disk:* FFS2, the installer's default, can lose the newest
articles in a crash. So can a disk with a write cache. FFS1 on an
uncached disk lost nothing. Before installing, give /var/fn its own
FFS1 partition. This erases sd1:

    fdisk -iy sd1
    printf 'a a\n\n\n4.2BSD\nw\nq\n' | disklabel -E sd1
    newfs -O 1 /dev/rsd1a
    mkdir -p /var/fn
    echo '/dev/sd1a /var/fn ffs rw,nodev,nosuid 1 2' >> /etc/fstab
    mount /var/fn

*Install:* Under /usr/local, which is mounted wxallowed:

    sha256 -C SHA256SUMS fn-6.7.N-openbsd-amd64.tar.gz
    mkdir -p /usr/local/src
    tar -xzf fn-6.7.N-openbsd-amd64.tar.gz -C /usr/local/src
    sh /usr/local/src/fn/install.sh

*The names:* /usr/local/fn, the account _fn, the folder /var/fn,
rcctl, and syslog for the log.

    cd /var/fn
    su -s /bin/sh _fn -c 'PATH=/usr/local/fn/bin:$PATH exec sh'

*Ports:* _fn cannot bind below 1024. Use --port 11563 and a
tls_port above 1024, or redirect with pf.
