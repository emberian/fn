Summary: Link two nodes: invite, accept, confirm, then the feed.

Two nodes can swap articles, encrypted, both ways. You are
news.example.org at 203.0.113.7; your friend is 198.51.100.9.

*Keys, both:* note the principal HEX it prints.

    fn operator CONFIG peer keygen /var/lib/fn/keys

*Invite (you), accept (friend), confirm (you):* send the files to
each other.

    fn operator CONFIG peer invite friend 'local.*' 198.51.100.9 119 \
        news.example.org /var/lib/fn/keys /var/lib/fn/invite \
        203.0.113.7 119
    fn operator CONFIG peer accept /var/lib/fn/invite /var/lib/fn/keys \
        friend.example.net 198.51.100.9:119 /var/lib/fn/accept
    fn operator CONFIG peer confirm /var/lib/fn/accept \
        /var/lib/fn/invite

*The feed, both:* a login for the other node, then pull.

    fn operator CONFIG principal set-password friend-node \
        --principal PRINCIPAL-HEX --posting
    fn operator CONFIG peer set friend --send 'local.*' --tls starttls \
        --server-name 198.51.100.9 --anchor /var/lib/fn/friend-cert.pem
    fn operator CONFIG peer login friend me-node \
        /var/lib/fn/friend.fnauth
    fn operator CONFIG peer pull friend 20

Post on one, read on the other. help peer explains every flag.
