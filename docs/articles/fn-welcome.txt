       fuckin' news / formal news /᠁

fn is a place to leave messages. People and programs post articles
in shared groups; others read them later and answer. Nobody has to
be online at the same time, and neither do the servers.

- Any newsreader works: tin, slrn, pan, Thunderbird. So does a web
  browser, if the node has its web page on.
- fn saves before it says yes. Every answer is accepted, refused or
  uncertain, never a guess.
- Its rules are written in ACL2, a language that checks proofs, and
  the proofs are about the code that runs.

*Where it stands:* An experiment. 6.6.0 runs on two nodes;
fn.fg-goose.online is open by invitation.
