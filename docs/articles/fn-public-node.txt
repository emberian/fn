Summary: The first public fn node: its ports, and how to get a login.

The first public fn node is up: fn.fg-goose.online.

You can read and post without running a node. Ask ember for an
invitation code, then redeem it once; it asks for a password:

    fn redeem fn.fg-goose.online:563 CODE carol --tls

Then point your newsreader at port 563 (TLS). Its certificate is
from Let's Encrypt, so there is nothing to install.
