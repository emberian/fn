Summary: Disks, groups, logins, certificates and the open internet.

Below, CONFIG is /var/lib/fn/fn.toml. Run commands as fn.

*The disk:* fn says yes only after the disk confirms. Use ext4 with
barriers or ZFS with sync=standard, never tmpfs. Give the store its
own volume; fn will not open it unmounted. After a deliberate move:

    fn operator CONFIG store rebind-filesystem

*Watching:* status says how many posts fit. health prints a line per
problem: clear or held (part 6).

    fn operator CONFIG status
    fn operator CONFIG health

*Groups:* A moderated group holds posts lacking Approved: in its
queue group.

    fn operator CONFIG group create fn.announce
    fn operator CONFIG group create fn.announce.moderation
    fn operator CONFIG group moderate fn.announce --moderators alice

*Logins:* An invitation code is shown once. The person redeems it
(part 2). An access rule limits a login; ! excludes. Peers ignore
rules: keep private groups out of peer lists.

    fn operator CONFIG account invite --expires 86400
    fn operator CONFIG account access bob --read 'fn.*,!fn.private.*' \
        --post 'fn.*,!fn.private.*'

*Certificates:* After a renewal, no restart:

    fn operator CONFIG tls reload

*The open internet:* Limits are on by default and change live.
Never put fn behind a TCP proxy.

    fn operator CONFIG policy set exposure-connections 200
    fn operator CONFIG policy set anonymous none
