Summary: Disks, groups, logins, certificates and the open internet.

CONFIG is /var/lib/fn/fn.toml. Run commands as fn.

*The disk:* fn says yes only after the disk confirms. Use ext4 or
ZFS, never tmpfs, and give the store its own volume.

*Watching:* status says how full it is; health prints one line per
problem (part 6).

    fn operator CONFIG status
    fn operator CONFIG health

*Groups and logins:* An invitation code is shown once.

    fn operator CONFIG group create fn.announce
    fn operator CONFIG account invite --expires 86400

*Certificates:* After a renewal, no restart:

    fn operator CONFIG tls reload

*The open internet:* Limits are on by default. Never put fn behind
a TCP proxy.
