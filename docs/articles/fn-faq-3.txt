Summary: From the release file to a node others can reach.

Six commands and a certificate make a node.

*What you need:*
- Linux x86-64 with systemd, glibc 2.36 or later and OpenSSL 3:
  Debian 12 or Ubuntu 24.04. Minimal Debian 12 also needs
  libssl3, openssl and sudo.
- Or OpenBSD 7.9: see the follow-up to this article.
- Root, and a disk that keeps its word (part 4).

*Install, as root:* This makes /opt/fn, the account fn, /var/lib/fn
and a stopped service.

    sha256sum -c --ignore-missing SHA256SUMS
    tar -xzf fn-6.7.N-linux-x86_64.tar.gz
    sh fn/install.sh

*Configure, as fn:* Give your real address; 0.0.0.0 is refused.

    cd /var/lib/fn
    sudo -u fn env PATH=/opt/fn/bin:$PATH sh
    fn operator /var/lib/fn/fn.toml mission small-community \
        --host 203.0.113.7 --port 119

small-community means logins over TLS, and the groups
local.general, local.test and control.cancel. For tin, add
tls_port = 563 under [listener].

*A certificate:* Copy yours to tls/cert.pem and tls/key.pem, or:

    openssl req -x509 -newkey ec -pkeyopt ec_paramgen_curve:P-256 \
        -nodes -days 3650 -subj /CN=news.example.org \
        -addext subjectAltName=DNS:news.example.org,IP:203.0.113.7 \
        -keyout tls/key.pem -out tls/cert.pem
    chmod 600 tls/key.pem

*The store, its name, a login:* CONFIG is /var/lib/fn/fn.toml.

    fn operator CONFIG init  # docs-check: skip (mission)
    fn operator CONFIG policy set path-identity news.example.org
    fn operator CONFIG principal set-password alice --posting

*Start, as root:* Every health line should say clear.

    systemctl enable --now fn
    fn operator CONFIG health
