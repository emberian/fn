# Ordinary release and private credit authority

A workspace owner/generation match does not authorize return of a range bearing
private credit authority. The independent specification now denies that ordinary
return with `:credit`, retains the complete pool, and records only the first
pool-release stop. Its predicates read the schema positions and its effects use
pure list updates; the oracle calls no production pool or CNS handler.

The original ownership-reclamation and counted CNS antecedents are unchanged.
They permit typed credit-tagged logical inputs. This coverage does not establish
that ordinary CNS admission can obtain private-credit ranges.

The raw pool component checks credit authority before query references. Public
CNS draining first preflights all relevant query references: a query-held credited
range therefore retains the complete state with the existing nonrunnable charge.
After its last query reference closes, ordinary release still lacks private credit
authority. The lease refusal uses the arm's empty-work charge; final workspace or
namespace refusal uses its explicit state-work charge.

Final cleanup is sequential. A credited workspace denies the first return. A
credited namespace denies the second return after the ordinary workspace has
already returned; no namespace mutation, row reclaim, timer clear, or rollback of
that completed workspace return is specified. Credit accounting and every sibling
remain framed by the complete expected core.

The prior uncredited model remains a named historical oracle. New by-definition
equivalence statements retain its behavior for uncredited relevant ranges. The
new source controls assert the whole original antecedent and complete new result,
and require the actual result to falsify the historical oracle on credited inputs.
Raw controls also combine credit with a query reference and an existing sticky
stop. Public controls cover both final ranges, last-reference close/retry, and the
defensive held-lease branch. That branch remains unreachable-in-composition under
the present caller paths.

These changes and controls are source candidates. They have passed strict reader,
diff and secret checks; no current application admission or execution is claimed.
