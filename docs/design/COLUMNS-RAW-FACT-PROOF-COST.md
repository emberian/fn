# Reuse public accessor facts for raw terms

The raw NTH type/bound proofs generated by `fn2-columns-accessor-events` now
use the corresponding already-admitted public accessor theorem. Their theory
contains only the public reader, raw reader and row accessor definitions plus
`minimal-theory`. Unfolding these functions gives the same raw conclusion and
antecedent; the only remaining difference is conjunction order.

This changes two hint templates only. Every generated function, guard,
theorem name, full hypothesis/conclusion and rule class remains unchanged.
The public facts occur before the raw facts, so this introduces no proof cycle.
The generator continues to emit and prove both named public interfaces.

In the actual upload refusal log at source `6701`, the 70-array table reached
only 49 accessor pairs before its original 20-second macro limit. The 98 raw
facts processed so far cost 1.84 seconds total / 1.00 seconds proving (rounded
per-summary times). They independently used array predicate and shape facts
already used to establish the immediately preceding public accessor theorem.
The change avoids that repeated proof search; its actual speedup remains
unmeasured. It is intended to compose with the separate theory-event batching
pilot under one unchanged original-macro 2M-step / 20-second gate, not to split
the macro, omit any facts, raise a limit, or modify executable representation.

The source-executed generator control compares the old and new actual emitter
across 70 mixed-width/enum columns, plus empty and one-column boundaries. It
checks earlier-public-theorem references and exact accessor-only hints. After
removing only those hints, every emitted form is equal; exactly 140 hint events
