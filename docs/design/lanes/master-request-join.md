# Actual maintenance request, inventory and resume join

This source slice connects the sealer's actual CHECKPOINTING state to MASTER
pressure, bounded root1 inventory transitions and a checked post-reopen wake.
Activation remains NIL. Eleven source controls pass; the prepared signed-client
APPEND/SIM fixture has not run. Neither is macroemission, ACL2 admission or physical
refinement qualification.

The lower pressure implementation is extracted unchanged except for the internal
requested hint. Layout readiness, root1/snapshot IDLE, allocator thaw/token0,
directory headroom and the actual reservable bundle predicate remain common
conjuncts. Only the retirement trigger becomes `(debt-trigger OR requested)`.
Both actual MASTER IDLE and its wait-grant readiness obtain the hint from the
checked sealer snapshot helper. This does not bypass unchanged pool shortages or
replace the later HELD admission and inactive-bank scan.

STEP's `:inventory` result enters the new `:root1-inventory` state. Its separate
callback receives the actual pure-byte quantum, owner row and generation. It
returns to STEP after `:more`; yield/wait/error distinctions remain. This state
retains the same abstract working bundle as source processing. No descriptor
credit is used as a byte-copy budget and no source-complete flag is supplied.

The existing typed promote/rebase/reopen route is preserved. After successful
snapshot release, `:sealer-resume-wake` calls the actual checked wake-target helper.
That helper permits a target only after adopted catalog/original retirement and
resource release agree. An absent target is harmless. The wake state has no
storage-window hold and continues into the existing teardown transfer path.

Canonical late materialization calls are extracted from the actual donor and
placed before MASTER materialization. The current CNS include/body and auth/CNS
emissions are preserved. No B coordinator, commit decision, recovery authority or
activation constant is replaced. Coordinator source hashes are regression controls.

The slice deliberately does not transplant missing providers. The accompanying
source-map JSON records literal missing includes plus pre-index corechild/kind,
startup row creation and exact-cost binding frontiers. The provider ABI must match
the current guarded coordinator. The prepared fixture uses real image creation,
signed client transport and shared SIM pumps, with the existing explicit TEST-ONLY
CATALOG entry under NIL; it is not an automatic maintenance activation witness.
