
## Peer receipt versus consumed Send source

The current host/replay donor separates these subjects explicitly. Replay validates a non-cancelled Send's recorded source bytes against its still-owned loan; cancelled Send retains the native NIL-payload convention and derives its consumed prefix from that loan before posting. Capability field 3 is a consumed-source transcript, not a delivery counter. Field 8 stores successful exact segments and failed/cancelled unknown-prefix constraints. The actual client RX observation is checked against those constraints; replay without a client observation does not establish receipt.

`sim/envelope-output.lisp` provides a resumable matcher: one step handles a list cell, peer byte or boolean-row cell. Ordinary exact output and a final single unknown prefix take a linear path. Ambiguous intermediate prefixes use dynamic-programming rows, with polynomial work proportional to remaining source bytes times remaining peer bytes; there is no recursive search backtracking. The convenience checker supplies a structurally derived work budget, not a stored-data ceiling. ### Next semantic proof boundary

The next narrow lemma is the row recurrence for one source octet, stated against the independent `fn2-envelope-output-language-p`, not the runtime matcher. Restrict the theorem to proper octet segments and peer suffixes. In phases 7–9, let `suffix[i]` denote membership of peer suffix `p[i:]` in the following-segment language, and `row[i]` denote membership in the language of the unprocessed remainder of the current segment followed by those segments. Prepending source octet `b` gives `new[i] = (i < len(p) and p[i] = b and row[i+1])` for an exact segment. For a prefix segment it gives `new[i] = suffix[i] or (i < len(p) and p[i] = b and row[i+1])`. Keeping the following-segment row distinct from the current remainder row is essential.

First prove the independent language's exact/prefix one-byte decomposition under proper-octet domain predicates, then prove a single phase-8 cell preserves this row interpretation. This isolates the semantic transition before adding list reversal and phase composition. The corresponding fuel obligation is a phase-dependent potential decreasing on every nonterminal step, including validation and reversal; derive the wrapper budget from its initial value. Neither theorem is claimed by the current two-book record. Subsequent work should expose generated field-update/frame facts if hand-maintained state plumbing obscures these local invariants, without introducing a second matcher.
